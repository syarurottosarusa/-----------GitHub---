# 付け回しシステム MVP

## 概要

キャスト（接客スタッフ）の席配置や接客状況を管理するための、簡易的な業務シミュレーションアプリです。

飲食・接客業で行われる「どのスタッフをどの卓へ付けるか」という管理業務を想定し、卓ごとの状態や接客状況をリアルタイムで確認できるようにしています。

Python と Streamlit を使用して開発しました。

## 主な機能

* 20卓分の接客状況を一覧表示
* スタッフ指名状態の管理
* 延長処理と残り時間表示
* 卓ごとの接客状態を色分け表示
* 手動での実績登録
* 接客スケジュールの自動更新

## 起動方法

### 1. リポジトリをダウンロード

```bash
GitHub の「Code」ボタンから URL を取得してください
```

### 2. プロジェクトフォルダへ移動

```bash
cd tsukemawashi-system-mvp
```

### 3. 必要ライブラリをインストール

```bash
pip install -r requirements.txt
```

### 4. Streamlit を起動

```bash
streamlit run app.py
```

## 学習・改善ポイント

開発中に、画面表示や状態管理に関するいくつかの問題を修正しました。

### 延長処理後の表示更新

延長ボタン押下後、セット時間は変更されているのに卓カード側へ反映されない問題がありました。

set_time 更新後にスケジュールを再計算することで、表示内容が正しく更新されるよう修正しました。

### 卓カード表示と現在状態の同期

卓カードに現在の状態ではなく、別時間帯の予定が表示される問題がありました。

現在時刻に該当するスケジュールのみ表示するよう修正しました。

### Streamlit の再描画処理

st.rerun() の位置が不適切だったため、画面が繰り返し再描画される問題がありました。

ボタン操作時のみ再描画されるよう修正しました。

### session_state を使った状態管理

画面更新時に入力内容や選択状態が消える問題があったため、session_state を用いて状態保持を行いました。

これらの修正を通じて、

* 状態管理
* 再描画制御
* ロジック分離
* エラー原因の切り分け

について理解を深めました。
